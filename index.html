새 저장소를 궤도에 올리는 법

  1. 바로 반영(권장): 화면 아래 [저장소 반영] → 미반영 목록에서 체크 → 분류 고르기 → [선택 반영]. Pages 켜기·카운터 설치·분류가 한 번에 됩니다 (관리자 토큰 필요).
  2. 자동: gurifire 공개 저장소에 index.html을 올리고 GitHub Pages를 켜면 최대 10분 뒤 궤도에 나타납니다. 이용자 수는 index.html의 </body> 바로 앞에 아래 한 줄이 있어야 집계됩니다.

숫자 읽는 법

  1. 사용자는 기기 기준입니다. 같은 사람이 폰과 PC로 들어오면 2명으로 셉니다. 브라우저 데이터를 지우면 새 기기로 셉니다.
  2. 방문은 앱을 연 횟수입니다. 새로고침도 1회로 셉니다.
  3. 지금 접속은 최근 2분 30초 안에 화면을 띄워 둔 기기 수입니다.
  4. 이름·위치·입력 내용은 보내지 않습니다. 무작위 기기 ID와 시각만 저장합니다.

관리자 토큰

오비트에서 저장소를 바로 반영하려면 GitHub 토큰이 필요합니다. 토큰은 이 기기 브라우저에만 저장되고 GitHub(api.github.com)에만 보냅니다. 공용 PC에는 저장하지 마세요.

토큰 만들기 (처음 한 번, 약 2분)

  1. 아래 [GitHub 토큰 만들기]를 누릅니다 (gurifire 계정 로그인 상태).
  2. Token name: orbit · Expiration: 90 days
  3. Repository access: All repositories
  4. Permissions의 Repository permissions에서 Contents, Pages, Administration을 Read and write로 바꿉니다.
  5. [Generate token] → github_pat_로 시작하는 값을 복사해 아래에 붙여넣습니다.

Administration은 Pages 켜기에만 쓰입니다. 빼고 만들면 Pages만 저장소 설정에서 직접 켜고, 나머지(카운터 설치·분류·제외)는 그대로 됩니다.
